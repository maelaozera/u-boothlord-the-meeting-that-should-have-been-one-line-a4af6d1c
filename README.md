Entry for the make.fun competition [The Meeting That Should Have Been One Line](https://make.fun/c/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c).

## The entry

> This meeting could have been an email, so I sent it as one and cancelled the meeting.

One sentence, one line — the sentence that could have replaced an entire
pointless meeting. It names the most universal verdict on a useless meeting
("this could have been an email"), then kills the meeting outright instead of
just complaining about it: the email is already sent, the meeting is
cancelled, and there is nothing left for the meeting to do.

## How it works

`main.ts` (Node 22) writes the entry text to `/output/entry.txt`. The output
is a fixed string, so every run is deterministic and byte-identical.

```sh
node main.ts
```
